# 详细锅炉模型 - 再热Rankine循环仿真

## 概述

本文档介绍了详细锅炉模型的实现，该模型相比简化的`SimpleHeatExchanger`锅炉，更真实地模拟了典型火电厂锅炉的内部结构和工作原理。

## 模型文件

- **`detailed_boiler_rankine_model.py`**: 完整的详细锅炉模型实现

## 锅炉的核心作用

锅炉是传统热电厂中与汽轮机紧密配合的"能量心脏"。如果说汽轮机是负责能量转换和做功的"肌肉"，那么锅炉就是制造高压高温蒸汽、为整个系统提供动力源泉的"胃"和"肺"。

它的核心作用是：**通过燃烧燃料，将水高效、安全地转化为特定参数（高温、高压）的过热蒸汽，以供汽轮机使用。**

## 锅炉的三个关键组成部分

### 1. 省煤器（Economizer）

**作用**: 利用尾部烟气余热预热给水

- **位置**: 锅炉尾部烟道
- **过程**: 给水泵将除盐水打入锅炉，首先进入省煤器。在这里，尚未沸腾的冷水利用锅炉排出的、温度仍然较高的烟气进行预热。
- **目的**: 
  - 提高给水温度至接近饱和温度
  - 回收烟气余热，节省燃料
  - 提高锅炉效率
- **状态变化**: 液态水温度升高（但仍保持液态）

### 2. 水冷壁（Waterwall）

**作用**: 炉膛辐射传热，水蒸发成饱和蒸汽

- **位置**: 锅炉炉膛四周的墙壁，由密集的管道组成
- **过程**: 预热后的水进入水冷壁管道。在炉膛中心，燃料与空气混合并剧烈燃烧，产生高达1400-1600°C的火焰和高温烟气。高温主要通过**辐射传热**的方式，将巨大的热量传递给水冷壁管内的水。
- **结果**: 水在水冷壁内吸收足够热量后，开始沸腾并完全蒸发，变成饱和蒸汽
- **特点**: 
  - 这是水吸收热量最多的阶段
  - 吸热量占锅炉总吸热的60-70%
  - 主要是汽化潜热
- **状态变化**: 液态水 → 饱和蒸汽（干度x=1）

### 3. 过热器（Superheater）

**作用**: 饱和蒸汽继续加热成过热蒸汽

- **位置**: 炉膛上方或出口的烟道中
- **过程**: 从水冷壁出来的饱和蒸汽，汇集后进入过热器。过热器由一系列蛇形管排组成，高温烟气通过对流和辐射的方式继续加热这些管内的饱和蒸汽。
- **目的与结果**: 
  - 饱和蒸汽被继续加热，温度升高而压力基本保持不变，变成过热蒸汽
  - **提高效率**: 过热蒸汽在汽轮机中膨胀做功时，不会立即凝结成水滴，能保持较高的干度，从而提高了汽轮机的内效率
  - **保护设备**: 防止饱和蒸汽在汽轮机末级叶片中凝结成水滴，冲击并侵蚀叶片
- **状态变化**: 饱和蒸汽 → 过热蒸汽（温度继续升高）

## 模型架构

### 系统配置

```
给水 → 省煤器 → 水冷壁 → 过热器 → 高压缸 → 再热器 → 低压缸 → 凝汽器 → 给水泵
```

### 主要组件

1. **锅炉系统**:
   - 省煤器 (`SimpleHeatExchanger`)
   - 水冷壁 (`SimpleHeatExchanger`)
   - 过热器 (`SimpleHeatExchanger`)
   - 再热器 (`SimpleHeatExchanger`)

2. **汽轮机系统**:
   - 高压缸 (`Turbine`)
   - 低压缸 (`Turbine`)

3. **辅机系统**:
   - 凝汽器 (`Condenser`)
   - 给水泵 (`Pump`)
   - 循环水系统

## 关键设计参数

### 锅炉系统

| 组件 | 压降 | 主要功能 |
|------|------|----------|
| 省煤器 | 2% | 预热给水至330°C（接近饱和温度） |
| 水冷壁 | 3% | 水蒸发成饱和蒸汽（x=1） |
| 过热器 | 5% | 饱和蒸汽加热至600°C过热蒸汽 |
| 再热器 | 3% | 高压缸排汽再次加热至600°C |

### 主要工况参数

- **主蒸汽参数**: 150 bar, 600°C, 10 kg/s
- **再热蒸汽温度**: 600°C
- **凝汽器背压**: 0.1 bar
- **循环水温升**: 20°C → 30°C

## 详细模型 vs 简化模型

### 简化模型
- 使用单一的`SimpleHeatExchanger`作为锅炉
- 直接从给水变为过热蒸汽
- 无法体现锅炉内部的状态变化

### 详细模型优势

✓ **真实反映锅炉内部工质的三个状态变化**:
  - 省煤器: 预热（液态水温度升高）
  - 水冷壁: 蒸发（液态水→饱和蒸汽）
  - 过热器: 过热（饱和蒸汽→过热蒸汽）

✓ **可以单独分析各段的性能和设计参数**

✓ **可以优化各段的热量分配**

✓ **便于分析锅炉的压降和热效率**

✓ **更接近真实电厠的锅炉配置**

## 典型结果分析

### 锅炉各段吸热占比

- **省煤器**: ~15-20% (预热段)
- **水冷壁**: ~60-70% (蒸发段，主要吸热) ⭐
- **过热器**: ~15-20% (过热段)

**理论分析**: 水冷壁吸热占比最大，这是因为水的蒸发潜热很大。在水从液态变为气态的过程中，需要吸收大量的热量。

### 典型性能指标

- **净发电功率**: 15-16 MW
- **循环热效率**: 40-42%
- **排汽干度**: 0.88-0.94
- **厂用电率**: ~1.3%

## 技术要点

### 干度（x）的含义

在两相区（气液共存区），干度x表示蒸汽质量占总质量的比例：
- x = 0: 饱和液态
- 0 < x < 1: 湿蒸汽（气液混合）
- x = 1: 饱和蒸汽
- x < 0 或 x > 1: 过冷或过热（单相区）

### 饱和状态

- **饱和温度**: 在给定压力下，水开始沸腾的温度
- **饱和压力**: 在给定温度下，水开始沸腾的压力
- **饱和蒸汽**: 刚好完全蒸发的蒸汽（x=1），再加热就变成过热蒸汽

### 过热度

过热蒸汽温度与同压力下饱和温度的差值：
```
过热度 = T_过热 - T_饱和(p)
```

例如：150 bar下，饱和温度约342°C，主蒸汽600°C，过热度约258K
