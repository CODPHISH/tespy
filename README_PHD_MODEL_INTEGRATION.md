# 阶段2改进：博士模型参数整合

## 概述

本文档说明如何整合博士提供的设计模式数据，改进我们的Stage2简化模型。博士提供的数据位于 `boiler-turbine_design_state` 目录中，包含了一个完整的、真实的锅炉-汽轮机系统的设计工况计算结果。

## 📁 博士提供的数据文件

```
boiler-turbine_design_state/
├── connections.csv              # 68个连接点的详细热力参数
├── busses.json                  # 汽轮机各段的功率输出
└── components/
    ├── HeatExchanger.csv        # 12个换热器的kA、Q等参数
    ├── Turbine.csv              # 9段汽轮机的效率、功率
    ├── Pump.csv                 # 给水泵参数
    ├── Valve.csv                # 各阀门的压降
    ├── Pipe.csv                 # 管道参数
    ├── DiabaticCombustionChamber.csv  # 燃烧室参数
    └── ...
```

## 🔍 博士模型关键特点

### 系统拓扑
博士的模型比我们的简化模型更详细：

| 子系统 | 博士模型 | 我们的简化模型 |
|--------|----------|---------------|
| **汽轮机** | 高压缸2段 + 低压缸7段 | 高压缸1段 + 低压缸1段 |
| **过热器** | 4级串联（低过、屏过、三过、末过） | 1个综合过热器 |
| **再热器** | 2级串联（低再、高再） | 1个综合再热器 |
| **省煤器** | 2级串联（上省、下省） | 1个综合省煤器 |
| **燃烧室** | ✅ 有（DiabaticCombustionChamber） | ❌ 无（使用烟气源） |
| **空预器** | ✅ 有 | ❌ 无 |
| **煤气预热器** | ✅ 有 | ❌ 无 |

### 关键参数对比

| 参数 | 博士模型 | 原始简化模型 | 说明 |
|------|----------|-------------|------|
| 主蒸汽压力 | 161 bar | 150 bar | 博士模型更接近实际 |
| 主蒸汽温度 | 560 °C | 600 °C | 博士模型更保守 |
| 主蒸汽流量 | 79.9 kg/s | 100 kg/s | 博士模型更小 |
| 再热压力 | 40 bar | 30 bar | 博士模型更高 |
| 再热温度 | 512 °C | 600 °C | 博士模型更保守 |
| 烟气温度 | 1485 °C | 1200 °C | 博士模型更高（燃烧室） |
| 烟气流量 | 135.2 kg/s | 300 kg/s | 博士模型更小 |
| 凝汽器压力 | 0.12 bar | 0.05 bar | 博士模型真空度低 |
| 汽轮机效率 | 0.7473-0.7475 | 0.86-0.88 | 博士模型更真实 |
| 泵效率 | 0.85 | 0.78 | 博士模型更高 |

### 烟气成分

博士模型使用的烟气成分（来自混合煤气燃烧）：
```python
{
    'N2': 0.6220,    # 62.2% 氮气
    'O2': 0.0205,    # 2.05% 氧气
    'CO2': 0.3061,   # 30.61% 二氧化碳
    'H2O': 0.0513,   # 5.13% 水蒸气
}
```

我们原来使用的烟气成分（典型燃煤）：
```python
{
    'N2': 0.70,      # 70% 氮气
    'O2': 0.08,      # 8% 氧气
    'CO2': 0.12,     # 12% 二氧化碳
    'H2O': 0.10,     # 10% 水蒸气
}
```

**主要差异**：博士模型的CO2含量远高（30.61% vs 12%），这是因为使用了高炉煤气、焦炉煤气等混合燃料。

## ⚠️ 已知问题与局限

### 1. 省煤器kA值为NaN

**原因**：
- 博士模型的省煤器出口温度约束（276°C）与简化模型的烟气流动路径不完全兼容
- 在简化的单级省煤器中，该温度约束可能过于严格

**解决方案**：
- 放松省煤器出口温度约束
- 或者增加更多的中间温度测点

### 2. kA值差异巨大

**示例**：
- 水冷壁：106 kW/K (博士) vs 823,000 kW/K (简化)
- 过热器：341 kW/K (博士) vs 86,648 kW/K (简化)

**原因**：
- **单位可能不同**：博士模型的kA可能以MW/K为单位
- **多级vs单级**：博士使用4级过热器串联，简化模型用1个等效过热器
- **温差不同**：多级串联的温差分布与单级的对数平均温差不同

**物理解释**：
```
Q = kA × ΔT_lm

多级串联：
Q1 = kA1 × ΔT1
Q2 = kA2 × ΔT2
Q3 = kA3 × ΔT3
Q4 = kA4 × ΔT4
Q_total = Q1 + Q2 + Q3 + Q4

单级等效：
Q_total = kA_eq × ΔT_lm_eq

由于ΔT_lm_eq ≠ (ΔT1 + ΔT2 + ΔT3 + ΔT4)，
所以 kA_eq ≠ (kA1 + kA2 + kA3 + kA4)
```

### 3. 系统性能差异

博士模型参数运行的简化模型性能明显低于原始参数，这是**正常的**，因为：
- 博士模型使用了更真实（但更保守）的参数
- 真实电厂的汽轮机效率通常在0.75左右，不是0.88
- 真实的蒸汽温度受材料限制，不会太高

## 🎓 经验总结

### 1. 简化vs详细模型的取舍

**简化模型的优势**：
- ✅ 快速收敛
- ✅ 易于理解
- ✅ 调试方便
- ✅ 适合参数扫描

**简化模型的局限**：
- ❌ 温度分布不够精细
- ❌ kA参数不能直接对应
- ❌ 难以捕捉多级系统的细节

### 2. 参数整合策略

**可以直接整合的参数**：
- ✅ 主蒸汽压力、温度、流量
- ✅ 再热压力和温度
- ✅ 烟气温度和流量
- ✅ 烟气成分
- ✅ 汽轮机效率
- ✅ 泵效率

**需要谨慎处理的参数**：
- ⚠️ 换热器kA（需要等效转换）
- ⚠️ 压降分配（多级vs单级）
- ⚠️ 温度约束（需要放松）

### 3. 模型验证方法

1. **能量平衡检查**：总吸热 ≈ 净功率 + 凝汽放热
2. **性能对比**：简化模型的总体性能应与博士模型接近
3. **趋势一致性**：改变输入参数时，输出趋势应合理
4. **物理合理性**：所有温度、压力、流量都应在物理可行范围内
