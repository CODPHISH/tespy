# Stage2 详细模型验证报告

## 1. 报告概述

本报告详细记录了 Stage2 详细锅炉-汽轮机系统模型的验证过程，包括模型求解、结果对比、误差分析及结论。验证工作参照 "stage2组件数据分析" 指导文档，在新模型基础上执行求解，记录关键输出并与参考数据进行差异计算。

**报告生成日期**：2024  
**模型版本**：Stage2 完整详细模型 (stage2_detailed_model.py)  
**参考数据**：boiler-turbine_design_state/

## 2. 验证目标

本次验证的主要目标包括：

1. **模型收敛性验证**：确认模型能够在不依赖导出求解状态的情况下独立求解收敛
2. **结果精度验证**：对比求解结果与参考 CSV 数据，验证关键参数的一致性
3. **误差分析**：量化评估连接状态和组件性能的差异
4. **可复现性验证**：确保验证脚本可独立运行并重复产生结果

## 3. 模型概况

### 3.1 系统组成

Stage2 详细模型包含以下主要组件：

| 组件类型 | 数量 | 主要实例 |
|---------|------|---------|
| 汽轮机（Turbine） | 9 | 高压缸1-2段，低压缸1-7段 |
| 换热器（HeatExchanger） | 11 | 空气预热器、煤气预热器、蒸发器、各级过热器/再热器、省煤器 |
| 泵（Pump） | 1 | 给水泵 |
| 阀门（Valve） | 5 | 高压缸进/排气阀、中压缸进/排气阀、进水阀 |
| 燃烧室（DiabaticCombustionChamber） | 1 | 炉膛燃烧室 |
| 汽包（Drum） | 1 | 汽水分离装置 |
| 管道（Pipe） | 1 | 脱硫脱硝装置 |
| 分离器（Splitter） | 8 | 各级抽汽分离 |
| 混合器（Merge） | 2 | 燃料气混合 |
| 源/汇（Source/Sink） | 13 | 空气、燃料入口，烟气、抽汽出口 |
| **总计** | **52** | |

### 3.2 连接数量

模型共包含 **64** 个连接，涵盖：
- 水/蒸汽循环
- 烟气侧流动
- 燃料气/空气侧流动

### 3.3 工作流体

- **水/蒸汽循环**：纯水 (H₂O)
- **烟气/空气**：N₂, O₂, H₂O, CO₂
- **燃料气**：N₂, O₂, CO, CO₂, H₂, CH₄

### 8.3 典型差异分析

#### 8.3.1 固定边界条件的连接

对于设定为固定边界条件的连接（如主蒸汽、空气入口、燃料入口），求解结果应与参考值完全一致（差异为0或计算精度级别）。

#### 8.3.2 中间状态连接

中间状态连接（如各级汽轮机出口、换热器出口等）由网络方程求解得出，可能存在微小差异，主要原因：
1. 求解器收敛精度
2. 物性计算方法差异
3. 边界条件设置策略

#### 8.3.3 抽汽连接

所有低压缸抽汽出口和高压缸一段抽汽设定为 0 流量，仅高压缸排汽抽汽为 20 t/h，这些应与参考值完全一致。

## 9. 误差原因与可接受阈值

### 9.1 主要误差来源

1. **数值求解精度**
   - TESPy 求解器默认收敛容差：1e-4
   - 物性库（CoolProp）计算精度

2. **建模简化**
   - 辅助流路简化（如冷空气混合入口）
   - 部分小流量分支忽略

3. **边界条件策略**
   - 使用初始值而非固定值的连接会有小幅偏差
   - 求解策略（是否使用参考初始化）

### 9.2 可接受阈值说明

| 场景 | 阈值 | 判定标准 |
|------|------|---------|
| 固定边界条件 | 计算精度级别 (< 1e-6) | 应完全一致 |
| 关键性能参数（功率） | ±2% 或 ±0.1 MW | 工程可接受范围 |
| 主流路状态（温度、压力） | ±1% 或绝对值容差 | 测量精度范围 |
| 辅助流路状态 | ±5% | 次要影响 |
| 质量平衡 | < 0.1% | 物理守恒要求 |

### 9.3 超差情况处理

若出现超出容差的情况，应按以下步骤分析：

1. **确认数据来源**：检查参考 CSV 数据与模型输入是否一致
2. **检查物理合理性**：判断偏差是否在物理上可解释
3. **分析求解质量**：检查收敛残差和迭代次数
4. **调整容差或模型**：根据工程需求决定是否需要调整

## 10. 收敛性分析

### 10.1 收敛指标

模型求解的关键收敛指标：

| 指标 | 期望值 | 实际值 | 说明 |
|------|--------|--------|------|
| 收敛状态 | True | - | 求解器是否成功收敛 |
| 迭代次数 | < 100 | - | 迭代次数越少越好 |
| 最大残差 | < 1e-4 | - | 方程残差 |
| 求解时间 | < 60s | - | 计算效率 |

### 10.2 当前状态说明

**重要提示**：当前模型在不依赖导出求解状态的情况下求解时，存在以下情况：

1. **约束不足问题**：移除过多固定约束后，系统方程可能出现欠定
2. **循环依赖问题**：部分组件压力比约束与连接压力设定可能产生冲突

**解决方案**（已在代码中实施）：

```python
# 策略一：仅设置汽轮机效率，不固定压力比
turbine.set_attr(eta_s=0.7475)  # 设置等熵效率
# 不设置 pr，让网络自由求解压力分布

# 策略二：仅设置换热器传热系数
heat_exchanger.set_attr(kA=298000)  # 设置传热能力
# 不固定压降，让流动特性决定压力损失

# 策略三：泵保持压力比（维持主循环压升）
pump.set_attr(eta_s=0.85, pr=187.83)  # 必须保证给水压力
```

### 10.3 建议的求解策略

根据模型特点，推荐以下求解策略顺序：

1. **使用参考初始值**：从 CSV 提取的初始值提供良好的求解起点
2. **固定关键边界**：主蒸汽、燃料、空气入口
3. **放松中间约束**：中间连接使用初始值（p0, T0）而非固定值
4. **迭代调整**：若不收敛，逐步增加约束直至稳定
