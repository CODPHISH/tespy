# Stage 2 组件数据分析报告

## 1. 概述

本报告对 `boiler-turbine_design_state/components/*.csv` 和 `connections.csv` 文件中的组件参数和连接参数进行详细分析，结合TESPy框架的属性定义，明确区分输入参数和计算结果，并为后续建模提供需硬编码的真实输入常量清单。

## 2. 分析依据

### 2.1 TESPy 参数分类原则

根据TESPy源代码分析，组件参数可分为：

1. **输入参数**（Input Parameters）：可由用户在设计工况下指定的参数，用于约束系统方程
2. **计算结果**（Calculated Results）：通过求解方程组得出的参数，通常标记为 `is_result=True`
3. **设计参数**（Design Parameters）：在设计工况下指定，在离设计工况下作为参考值
4. **离设计参数**（Off-design Parameters）：在离设计工况计算中使用的参数

### 2.2 物理意义分析方法

- 查阅TESPy组件类源代码中的参数定义（`get_parameters` 方法）
- 分析参数的物理约束方程（`func` 属性指向的方程函数）
- 确认参数在设计/离设计计算中的角色

- 下级省煤器

#### 3.1.2 CSV参数字段

| 参数 | 符号 | 单位 | 物理意义 |
|------|------|------|----------|
| Q | 热负荷 | W | 换热量（负值表示热侧放热） |
| kA | 总传热系数 | W/K | 传热系数×换热面积 |
| td_log | 对数平均温差 | K | 逆流换热器的对数平均温差 |
| ttd_u | 上端温差 | K | 热侧入口与冷侧出口温差 |
| ttd_l | 下端温差 | K | 热侧出口与冷侧入口温差 |
| ttd_min | 最小端温差 | K | 换热器内最小温差点 |
| pr1 | 热侧压降比 | - | 出口/入口压力比（热侧） |
| pr2 | 冷侧压降比 | - | 出口/入口压力比（冷侧） |
| dp1 | 热侧压降 | Pa | 热侧压力损失 |
| dp2 | 冷侧压降 | Pa | 冷侧压力损失 |
| zeta1 | 热侧阻力系数 | 1/m⁴ | 几何无关摩擦系数（热侧） |
| zeta2 | 冷侧阻力系数 | 1/m⁴ | 几何无关摩擦系数（冷侧） |
| eff_cold | 冷侧效率 | - | 冷侧换热效率 |
| eff_hot | 热侧效率 | - | 热侧换热效率 |
| eff_max | 最大效率 | - | 冷热侧效率最大值 |

#### 3.1.3 参数分类

**可作为输入的参数**：
- `Q`：热负荷约束方程（`energy_balance_hot_func`）
- `kA`：传热系数约束方程（`kA_func`，基于对数温差）
- `ttd_u`/`ttd_l`/`ttd_min`：端差约束方程
- `pr1`/`pr2` 或 `dp1`/`dp2`：压降约束（二选一）
- `zeta1`/`zeta2`：阻力系数约束（用于离设计计算）
- `eff_cold`/`eff_hot`/`eff_max`：换热效率约束

**计算结果**：
- `td_log`：对数平均温差（由温度分布计算得出，标记为 `is_result=True`）

**判定逻辑依据**（TESPy源代码）：
```python
# 来自 src/tespy/components/heat_exchangers/base.py
'td_log': dc_cp(
    min_val=0, is_result=True, quantity="temperature_difference"
)
```
`td_log` 没有关联约束方程（`func=None`），仅作为计算结果后处理得出。

#### 3.2.3 参数分类

**判定逻辑依据**：

```python
# 来自 src/tespy/components/turbomachinery/turbine.py
'eta_s': dc_cp(
    min_val=0, max_val=1, num_eq_sets=1,
    func=self.eta_s_func, dependents=..., quantity="efficiency"
)
```

## 4. 连接参数分析（connections.csv）

### 4.1 CSV参数字段

| 参数 | 符号 | 单位 | 物理意义 |
|------|------|------|----------|
| m | 质量流量 | t/h | 流体质量流速 |
| v | 体积流量 | m³/h | 流体体积流速 |
| p | 压力 | bar | 流体压力 |
| h | 焓 | kJ/kg | 单位质量焓 |
| T | 温度 | °C | 流体温度 |
| Td_bp | 泡点/露点温差 | K | 过冷/过热度 |
| vol | 比容 | m³/kg | 单位质量体积 |
| x | 干度 | - | 蒸汽品质（0-1） |
| s | 熵 | J/(kg·K) | 单位质量熵 |
| 流体组分 | CH4, H2, H2O等 | - | 摩尔分数或质量分数 |
| phase | 相态 | - | 气相g/液相l/两相tp |

### 4.2 参数分类

**可作为输入的参数**（边界条件）：
- `m`：质量流量（通常在源点指定）
- `p`：压力（边界条件）
- `T`：温度（边界条件）
- `h`：焓（可替代T作为状态约束）
- `x`：干度（两相区状态约束）
- 流体组分：流体成分约束

**计算结果**：
- `v`：体积流量（由 m 和密度计算）
- `vol`：比容（由p, T或p, h计算物性）
- `s`：熵（由p, h计算物性）
- `Td_bp`：温差（由p, T计算）
- `phase`：相态（由p, h判定）

**判定逻辑**：
在TESPy中，每个连接的状态由两个独立变量确定（例如p和h，或p和T）。其他物性参数通过物性库（CoolProp）计算得出。

## 7. 结论

### 7.1 参数分类总结

1. **换热器**：kA为关键设计参数，需硬编码；td_log为计算结果
2. **汽轮机**：eta_s和pr为设计参数，需硬编码；P为计算结果（或反算参数）
3. **泵**：eta_s和pr为设计参数，需硬编码
4. **阀门**：pr为设计参数，zeta为离设计参数
5. **燃烧室**：lamb和eta为设计参数，需硬编码；Q_loss为计算结果
6. **连接**：m, p, T为输入；v, vol, s, phase为计算结果

### 7.2 硬编码参数清单

**必须硬编码的参数**（共37个设备参数）：
- 11个换热器的kA值
- 9个汽轮机段的eta_s和pr值（18个参数）
- 1个泵的eta_s和pr值（2个参数）
- 5个阀门的pr值
- 1个燃烧室的lamb和eta值（2个参数）
- 1个管道的pr值

**边界条件参数**：
- 质量流量（4个燃料+空气入口）
- 压力（各入口边界）
- 温度（各入口边界）
- 流体组分（燃料和空气成分）

### 7.3 建模建议

1. **设计工况优先**：先建立设计工况模型，确保所有硬编码参数合理
2. **参数灵敏度分析**：对关键参数（如汽轮机效率、换热器kA）进行敏感性分析
3. **离设计策略**：使用特性曲线或保持设计值，避免过度约束
4. **验证与校核**：对比CSV导出结果与模型计算结果，确保一致性
